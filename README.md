# Weather Mission

> **「今日の天気を、今日の行動に変える。」**  
> Open-Meteo API の気象データを取得・解析し、その日の環境条件に応じた最適な生活改善ミッションを自動選定・提案するレトロRPG風Webアプリケーション。

---

## 1. アプリケーション概要

Weather Mission は、大学の経営情報システム（MIS）系ゼミにおける「外部データ（REST API）の業務・意思決定への活用」の実習、および卒業制作「**Life Pilot: Reboot**」の先行開発プロトタイプとして開発された 1 画面完結型の Web アプリケーションです。

単なる「天気の閲覧」にとどまらず、取得した気象データ（最高気温、天候コード、降水確率）をリアルタイムに評価・加工し、利用者の行動意思決定（室内ストレッチ、屋内運動、屋外ウォーキングなど）に変換するデータ活用サイクルを体験できます。

## 3. システムアーキテクチャ & 使用技術

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES Modules)
- **気象データプロバイダ**: [Open-Meteo Weather Forecast API](https://open-meteo.com/en/docs)
  - エンドポイント: `https://api.open-meteo.com/v1/forecast`
  - 認証: 不要（非商用無料枠）
  - パラメータ: `current=temperature_2m,weather_code`, `daily=temperature_2m_max,precipitation_probability_max`, `timezone=Asia/Tokyo`, `forecast_days=1`
- **データ永続化**: Web Storage (LocalStorage)
- **テスト・品質検証**: Node.js `node:assert` による単体テスト (全15テストPASS), Puppeteer による実機画面キャプチャ

## 4. ミッション判定ルール（優先順位付き条件分岐）

優先度の高い条件を上から順に判定し、必ず最大1件のミッションを選定します。

| 優先度 | ルールID | 判定条件 | 提案ミッション | カテゴリ / 所要時間 |
|:---:|:---|:---|:---|:---:|
| **1** | `EXTREME_HEAT` | 今日の予想最高気温 $\ge 35.0^\circ\text{C}$ | 室内で軽くストレッチ | 室内ストレッチ (5分) |
| **2** | `SEVERE_WEATHER` | 大雨・雷雨コード (WMO 65, 67, 82, 95, 96, 99) | 屋内で5分間運動 | 室内運動 (5分) |
| **3** | `HIGH_PRECIP_PROB` | 今日の最大降水確率 $\ge 60\%$ | 室内で10分間運動 | 室内運動 (10分) |
| **4** | `COLD_WEATHER` | 今日の予想最高気温 $< 10.0^\circ\text{C}$ | 暖かい室内で軽く身体を動かす | 室内運動 (5分) |
| **5** | `OUTDOOR_WALK` | 上記いずれにも非該当（好天条件） | 外に出て10分間歩く | 屋外歩行 (10分) |
| **-** | `DATA_FALLBACK` | 気象データの欠損（気温取得不可など） | 室内で姿勢を正して深呼吸 | 室内ストレッチ (3分) |

> ⚠️ **安全上の注記**: 本ルールは教育実習用の暫定ルールであり、医学・気象学的な保証はありません。急な体調不良や局地的気象の悪化時は直ちに行動を中止・変更してください。

## 5. 主要機能

1. **3大都市のワンクリック切り替え**: 名古屋・東京・大阪の気象テレメトリを即座に取得・反映。
2. **リアルタイム・テレメトリ表示**: 現在気温、WMO天候アイコン、最高気温、降水確率、受信時刻を表示。
3. **意思決定理由の可視化**: なぜそのミッションが選ばれたのか（WHY）を明示し、納得感のある行動変容を促進。
4. **ミッション完了トグル & ログ記録**: 「MISSION COMPLETE!」操作により達成状態を記録し、LocalStorage に最新30件を保存。いつでも取消やログ消去が可能。
5. **検証用 DEMO シナリオ切替機能**: 猛暑日、大雨・雷雨、高降水確率、寒冷日、好天日の各条件分岐を発表・評価時に即座に実演可能。
6. **オリジナル・レトロ携帯ゲーム風 UI**: ドット絵調フォント（DotGothic16 / Press Start 2P）、ピクセルボーダー、控えめな走査線エフェクトによるレトロフューチャーな世界観。

## 6. ローカルでの実行・テスト方法

### 動作要件
- モダンWebブラウザ（Chrome, Edge, Firefox, Safari 等）
- Node.js (v18以上推奨) または Python 3

### ローカル起動
ES Modules を使用しているため、HTTP サーバー経由で開きます。

```bash
# Node.js を使用する場合
npx serve .

# または Python を使用する場合
python -m http.server 8000
```
ブラウザで `http://localhost:8000/` を開いて動作を確認します。

### 単体テストの実行
```bash
node tests/mission.test.js
```

## 7. 卒業制作「Life Pilot: Reboot」への発展構想

本アプリ「Weather Mission」は、卒業制作として開発予定のレトロゲーム風PWA『**Life Pilot: Reboot**』（AI人格が利用者を機体とし、パイロットとして生活改善指令を下す生活リズムハックアプリ）のコアエンジン先行開発です。

```
[ Weather Mission (現在) ]
  天気API ──> 決定的ルール分岐 ──> 行動ミッション提案

          ↓↓↓ 発展・統合

[ Life Pilot: Reboot (卒業制作) ]
  【外部・生体環境データ】
    ・天気予報 (Open-Meteo) ──┐
    ・利用者の気分・疲労度 ───┼──> 【安全決定エンジン (mission.js 拡張)】
    ・時刻・スケジュール ────┘          │
                                       │ 決定ミッション
                                       ▼
  【AI人格パイロット (Gemini API 連携)】
    ・鬼軍曹 / 愛犬 / 執事 ─────────> 【人格セリフ生成】
                                       │ 「外は雨だ！室内訓練に切り替えろ！」
                                       ▼
  【バトルミッションPWA】
    ・スマホ傾き・加速度センサーによる達成検知
    ・シンクロ率・サボりツケなどのゲームループ
    ・オフライン対応 PWA (Service Worker)
```

### 再利用資産
- `weather.js`: 天候データ取得とエラーハンドリング機構をそのまま PWA の環境センサー部として再利用。
- `mission.js`: 行動内容と安全性の決定権をアプリ側に残す「安全ファースト」アーキテクチャの基盤として継承（生成AIには行動決定権を持たせず、セリフ表現のみを任せる設計）。
- **LocalStorage 設計**: ミッション履歴と達成度管理ロジックを PWA のローカルステート管理へ発展。
